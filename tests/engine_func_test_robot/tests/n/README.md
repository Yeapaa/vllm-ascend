# n 参数测试

## 参数定义

- 协议层: `n: int | None = 1` (protocol.py:170)
- 采样层: `n: int = 1` (sampling_params.py:169)

## 约束规则

| 约束 | 值 | 说明 |
|------|-----|------|
| 类型 | `int` | 必须是整数 |
| 默认值 | `1` | 不传时使用默认值 |
| 最小值 | `>= 1` | 必须大于等于 1 |
| 贪婪采样 | `n=1` | temperature=0 时 n 必须为 1 |

## Pydantic 类型转换支持

| 输入类型 | 是否支持 | 转换结果 |
|---------|---------|---------|
| `int` (如 `1`) | ✅ | `1` |
| `float` (如 `1.0`) | ✅ | `1` |
| `str` (如 `"1"`) | ✅ | `1` |
| `null` | ✅ | 默认值 `1` |
| `bool` (如 `True`) | ⚠️ | `1` |
| `bool` (如 `False`) | ❌ | `0` → 报错 |
| `list` | ❌ | 报错 |
| `dict` | ❌ | 报错 |

- `test_n_abnormal.py`: 异常场景测试
- `test_n_boundary.py`: 边界场景测试
